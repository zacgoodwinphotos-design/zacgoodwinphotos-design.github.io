# Fitness Planner (standalone)

Runs entirely on your phone. No account and no server; it works offline after the first open.

## Install
1. Host this folder on any HTTPS static host (for example GitHub Pages).
2. Open the address in Chrome on Android and choose Install app.

## Your data
Everything is stored on the device. Use Backup > Export log (.md) regularly: it saves a Markdown file
with tables of every set, run and plan change. Import accepts that file (or an older .json backup).

## Updating the app
Replace the files on your host. The app picks up the new version the next time it opens with a connection.
